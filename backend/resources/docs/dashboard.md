# 📊 Panduan Menu: Dashboard & Indikator Utama

Selamat datang di **Dashboard SM Inventory ERP**. Halaman ini berfungsi sebagai pusat kendali (*command center*) yang menyajikan ringkasan performa penjualan, perputaran stok, dan status kas toko secara *real-time*.

---

## 🎯 Indikator Utama (Widget Metrik)

| Indikator | Penjelasan | Fungsi Operasional |
| :--- | :--- | :--- |
| **Omset Hari Ini** | Total penjualan kotor toko yang berhasil dibukukan pada hari kalender aktif. | Memantau pencapaian target penjualan harian toko/cabang. |
| **Transaksi Hari Ini** | Jumlah struk/nota penjualan yang berhasil selesai diproses kasir. | Mengukur tingkat keramaian pembeli dan *traffic* toko. |
| **Produk Stok Kritis** | Jumlah produk yang stok fisiknya sudah menyentuh atau di bawah batas minimum (*Min Qty*). | Peringatan dini agar admin segera menerbitkan Pesanan Pembelian (PO). |
| **Shift Kasir Aktif** | Jumlah kasir/terminal yang saat ini sedang dalam status shift terbuka (*Open*). | Memantau kasir mana saja yang sedang bertugas di meja kasir. |

---

## ⚡ Fitur Cepat & Pintasan Operasional

1. **Pintasan Cepat Header (Top Bar):**  
   Di bagian atas layar terdapat tombol cepat menuju menu harian paling sering digunakan:
   * **Produk:** Cek data harga dan stok barang.
   * **Pesanan Pembelian (PO):** Terbitkan pesanan ke pemasok.
   * **Cek Gudang:** Pengecekan stok fisik rak.
   * **Penerimaan Barang (GR):** Input faktur masuk barang datang.
   * **Koreksi Stok:** Penyesuaian selisih fisik.
   * **Stok Transfer:** Mutasi barang antar cabang.

2. **Pintasan Keyboard Universal:**
   * Tekan <kbd>Ctrl</kbd> + <kbd>K</kbd> (atau <kbd>Cmd</kbd> + <kbd>K</kbd>) untuk membuka **Pencarian Global** seluruh data produk, transaksi, dan pemasok.
   * Tekan <kbd>F1</kbd> untuk membuka buku petunjuk ini kapan saja.

## 💡 Tips & Catatan Penting
> [!TIP]
> **Penyaringan Cabang (Bagi User Pusat):** Jika Anda login sebagai manajemen pusat, gunakan filter cabang di widget untuk melihat performa spesifik cabang tertentu (misal: Cabang Sariwangi vs Cabang Pasir Hayam).
